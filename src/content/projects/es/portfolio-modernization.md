Caso de arquitectura frontend aplicado al propio portfolio profesional.

El objetivo no fue solo renovar una interfaz, sino construir una base clara para comunicar experiencia, proyectos y contacto sin depender de lógica innecesaria. La solución prioriza contenido estático, carga rápida, estructura bilingüe y mantenimiento simple.

## Decisiones principales

- Separar contenido y presentación mediante colecciones tipadas.
- Mantener rutas bilingües con una experiencia consistente entre español e inglés.
- Usar Astro para entregar páginas estáticas con bajo costo de ejecución.
- Organizar el contenido como piezas editables para facilitar futuras iteraciones narrativas.

## Resultado obtenido

El portfolio quedó estructurado como un sistema de contenido bilingüe, estático y tipado, con secciones que el equipo puede extender, revisar y adaptar sin comprometer performance, SEO ni claridad técnica.
